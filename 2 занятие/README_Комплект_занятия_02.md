# AI-культура — занятие 2 (полный пакет материалов)

Этот комплект собран для **магистратуры, трек «AI аналитика данных»**, занятие:

**«Введение в анализ данных. Где живут данные?»**

## Что входит в комплект

1. **Пакет для лектора**
   - `lesson02_master_guide.tex` — основной методический файл для Overleaf
   - `lesson02_master_guide.pdf` — собранный PDF
   - `lesson02_lecturer_cheatsheet.md` — короткий лист-подсказка на 1 экран
   - `AI_Culture_Lesson02_Open_Data_Instructor_v2.ipynb` — преподавательский Colab-ноутбук

2. **Пакет для студента**
   - `lesson02_student_longread.md` — текст для платформы / longread
   - `AI_Culture_Lesson02_Open_Data_Students_v2.ipynb` — студенческий Colab-ноутбук
   - `lesson02_dataset_passport_builder.html` — автономный HTML-конструктор паспорта датасета
   - `lesson02_no_code_workbook.xlsx` — no-code шаблон (сравнение источников + паспорт)

3. **Организация работы на потоке**
   - `lesson02_program_clusters_and_sources.xlsx` — матрица «программа → кластер → стартовые источники»
   - `lesson02_starter_sources.csv` — справочник стартовых источников для быстрой загрузки в Google Sheets/платформу

## Рекомендуемый сценарий использования

### До занятия
- лектор смотрит `lesson02_master_guide.pdf`
- команда согласует кластеры и стартовые темы через `lesson02_program_clusters_and_sources.xlsx`
- студентам заранее можно выдать `lesson02_student_longread.md`

### Во время занятия
- открыть `AI_Culture_Lesson02_Open_Data_Instructor_v2.ipynb`
- дать студентам либо `AI_Culture_Lesson02_Open_Data_Students_v2.ipynb`, либо `lesson02_no_code_workbook.xlsx`
- для no-code формата использовать:
  - браузер + Google Dataset Search / Kaggle / data.gov.ru / тематические порталы
  - `lesson02_no_code_workbook.xlsx`
  - `lesson02_dataset_passport_builder.html`

### После занятия
- студенты доделывают паспорт датасета дома
- преподаватель может проверить либо по workbook, либо по HTML/markdown экспорту, либо по ноутбуку

## Что здесь принципиально важно

Этот урок собран **не как обзор сайтов**, а как занятие про **выбор и верификацию источника данных до анализа**:
- кто владелец данных;
- когда датасет обновлялся;
- какая у него лицензия / ограничения;
- что является единицей наблюдения;
- какие риски есть до начала анализа;
- можно ли по этим данным отвечать на аналитический вопрос.

## Замечание по потоку ~70 человек

Материалы рассчитаны на аудиторию, где нельзя пускать всех в полностью свободный поиск.
Поэтому в пакете есть:
- кластеры направлений;
- стартовые источники по кластерам;
- no-code шаблон;
- единый артефакт пары: **паспорт датасета**.
