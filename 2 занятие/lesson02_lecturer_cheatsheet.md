# Lesson 02 — быстрый лист для лектора

## Центральная идея пары
Не «где скачать что угодно», а **как выбрать данные, пригодные для анализа**.

## На выходе студент должен уметь
- различать dataset / файл / портал / API;
- искать 3 релевантных источника;
- читать базовые метаданные;
- проверять лицензию и ограничения;
- выбирать 1 источник и оформлять паспорт датасета.

## Что показать в аудитории
1. Один табличный пример (CSV)
2. Один структурированный пример (JSON)
3. Один API-запрос
4. Один реальный поиск датасета по теме
5. Один разбор метаданных: publisher, update date, license, fields

## Что НЕ делать
- не уходить глубоко в pandas;
- не заставлять всех работать с Postman;
- не превращать занятие в каталог сайтов;
- не оставлять студентов без стартовых тем и кластеров.

## Базовый flow
- 10 мин — вход и постановка задачи
- 15 мин — мини-лекция
- 15 мин — демо 3 типов источников
- 30–35 мин — работа групп
- 10–15 мин — быстрые мини-защиты

## Базовый артефакт
Паспорт датасета:
- источник
- владелец
- дата обновления
- лицензия
- формат
- единица наблюдения
- ключевые поля
- риски
- возможная аналитическая задача

## Роль LLM
LLM можно использовать:
- чтобы расшифровать непонятные поля;
- чтобы сверстать черновой паспорт;
- чтобы перевести JSON в табличный вид.

LLM нельзя использовать как единственный источник истины:
- лицензия и условия использования проверяются вручную;
- описание полей сверяется с источником;
- вывод о пригодности данных студент формулирует сам.
