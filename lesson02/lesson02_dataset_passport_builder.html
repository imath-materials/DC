Конструктор паспорта датасета

Автономный no-code инструмент для занятия «Где живут данные?». Заполните поля, получите готовый паспорт и скопируйте его в markdown или JSON.

Ввод данных
Подсказка: сначала руками проверьте источник, дату обновления и лицензию. Не подставляйте эти поля «из головы».

Подходит для
Например: сравнение регионов, анализ динамики, сегментация, поиск трендов.
Ограничения
Например: старая дата обновления, неполное покрытие, неясная лицензия, отсутствует словарь полей.
Мини-чек-лист перед сдачей:
  1. Понимаю, кто собрал данные.
  2. Вижу дату публикации или обновления.
  3. Проверил(а) лицензию вручную.
  4. Понимаю, что означает одна запись.
  5. Могу объяснить, зачем этот набор нужен именно для моей темы.
